## 🍽️ Massaccesi Eventos

Sitio web desarrollado para **Massaccesi Eventos**, un servicio gastronómico orientado a eventos.

El objetivo del proyecto es presentar de forma clara y visual los servicios ofrecidos, mostrar información sobre la empresa y facilitar el contacto con potenciales clientes.

## 🌐 Sitio web

🔗 **[Visitar Massaccesi Eventos](https://exequielgimenez2605-oss.github.io/Massaccesi.eventos.github.io/)**

## ✨ Características

- 🏠 Página principal con presentación del servicio.
- 👥 Sección "Sobre nosotros".
- 🍽️ Presentación de diferentes menús.
- 🎉 Información relacionada con los eventos.
- 🔐 Acceso mediante contraseña para determinadas funcionalidades del evento.
- 📱 Diseño adaptable a distintos dispositivos.
- 💬 Contacto directo mediante WhatsApp.
